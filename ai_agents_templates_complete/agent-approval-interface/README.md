# Agent Approval Interface

**What it is / where it is used:** Review gate before an agent acts (Zapier, Cursor).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Approve/reject cards.

**What this version adds:** Decisions are saved locally.

**Run:** open `index.html` in a browser. No build step or dependencies.
