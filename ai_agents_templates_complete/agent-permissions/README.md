# Agent Permissions

**What it is / where it is used:** Access matrix for what each agent may do (GitHub apps, AWS IAM).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Toggle grid with risk badges.

**What this version adds:** Warns when agents can delete data.

**Run:** open `index.html` in a browser. No build step or dependencies.
