# AI Agent Profile

**What it is / where it is used:** Detail page for a single agent (Intercom Fin, Lindy).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Header summary with tabs for skills, runs, settings.

**What this version adds:** Tabs remember the last view.

**Run:** open `index.html` in a browser. No build step or dependencies.
