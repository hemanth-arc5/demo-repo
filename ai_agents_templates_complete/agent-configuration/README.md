# Agent Configuration

**What it is / where it is used:** Settings screen for one agent (Vercel, Azure AI Studio).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Grouped fields with live JSON preview.

**What this version adds:** Copy config JSON to clipboard.

**Run:** open `index.html` in a browser. No build step or dependencies.
