# Multi-agent Workflow

**What it is / where it is used:** Several agents handing work to each other (CrewAI, AutoGen).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Agent lanes with handoffs.

**What this version adds:** Shows which agent holds the work.

**Run:** open `index.html` in a browser. No build step or dependencies.
