# Agent Activity Log

**What it is / where it is used:** Streaming log of agent actions (LangSmith, Vercel logs).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Level filters, pause, auto-scroll feed.

**What this version adds:** Pause/resume and clear controls.

**Run:** open `index.html` in a browser. No build step or dependencies.
