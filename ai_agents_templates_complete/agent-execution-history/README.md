# Agent Execution History

**What it is / where it is used:** Table of past runs with a detail panel (GitHub Actions, Zapier).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Result filter, row detail panel.

**What this version adds:** Click or Tab+Enter a row for details.

**Run:** open `index.html` in a browser. No build step or dependencies.
