# Agent Workflow

**What it is / where it is used:** Visual flow of steps an agent follows (n8n, Make).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Connected nodes on a canvas.

**What this version adds:** Plain HTML/CSS nodes.

**Run:** open `index.html` in a browser. No build step or dependencies.
