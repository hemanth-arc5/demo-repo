# AI Agent List

**What it is / where it is used:** Directory of agents, used in admin consoles (Zapier, n8n).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Search, status filter, sort, grid/table switch.

**What this version adds:** Both views share one filtered list.

**Run:** open `index.html` in a browser. No build step or dependencies.
