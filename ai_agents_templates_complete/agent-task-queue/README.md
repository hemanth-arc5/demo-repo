# Agent Task Queue

**What it is / where it is used:** Ordered list of work waiting for an agent (Linear, Todoist).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Priority badges, drag to reorder.

**What this version adds:** Native HTML5 drag and drop, keyboard add.

**Run:** open `index.html` in a browser. No build step or dependencies.
