# Agent Status Monitoring

**What it is / where it is used:** Live health view for services and agents (Datadog, Grafana).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Health badge, sparkline, polling.

**What this version adds:** Hand-drawn SVG sparkline, no chart library.

**Run:** open `index.html` in a browser. No build step or dependencies.
