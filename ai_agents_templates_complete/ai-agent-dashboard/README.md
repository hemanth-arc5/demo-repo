# AI Agent Dashboard

**What it is / where it is used:** Overview screen showing agent health, success rate and recent activity (Datadog, LangSmith).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** KPI tiles, status badges, activity feed.

**What this version adds:** Local state and dark mode.

**Run:** open `index.html` in a browser. No build step or dependencies.
