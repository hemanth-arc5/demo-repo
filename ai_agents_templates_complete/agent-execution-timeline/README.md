# Agent Execution Timeline

**What it is / where it is used:** Step-by-step trace of one run (LangSmith, OpenTelemetry).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Vertical timeline with duration per step.

**What this version adds:** Steps colored by result.

**Run:** open `index.html` in a browser. No build step or dependencies.
