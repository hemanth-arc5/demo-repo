# Human-in-the-loop Workflow

**What it is / where it is used:** Agent pauses and waits for a person (Claude Code prompts, LangGraph).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Pending request, note, decision history.

**What this version adds:** Approve or reject with a note.

**Run:** open `index.html` in a browser. No build step or dependencies.
