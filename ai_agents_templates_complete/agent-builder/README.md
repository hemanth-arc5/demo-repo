# Agent Builder

**What it is / where it is used:** Form for creating an agent from model, prompt and tools (OpenAI GPTs, Lindy).

**Why it matters now:** AI agents act on their own, so people need interfaces to watch, steer and approve them.

**Patterns observed:** Tool chips, steps list.

**What this version adds:** Toggle tools and see steps.

**Run:** open `index.html` in a browser. No build step or dependencies.
